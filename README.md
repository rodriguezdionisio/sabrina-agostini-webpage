# Sabrina Agostini — Web

Landing page profesional para Sabrina Agostini, Licenciada en Nutrición.

## Objetivo

Crear una landing page simple, elegante y orientada a conversión, cuyo recorrido lleve al visitante desde el conocimiento de Sabrina hasta la reserva de un turno:

**¿Quién es? → ¿Puedo confiar? → ¿Cómo trabaja? → ¿Me sirve? → ¿Cuánto cuesta? → ¿Tengo dudas? → ¿Dónde atiende? → Quiero reservar.**

## Posicionamiento

- Nutrición basada en evidencia.
- Abordaje personalizado.
- Construcción de hábitos sostenibles.
- Orientación también a composición corporal y rendimiento deportivo, sin limitar la propuesta exclusivamente a deportistas.
- Atención presencial en La Plata y modalidad online en Argentina.

## Stack

- HTML
- CSS
- JavaScript vanilla
- Google Fonts

Sin framework ni backend por el momento.
